# The web front door (OliveTin panel)

An optional web panel that exposes mediastack's safe verbs as buttons, so
routine operations don't need a shell. It is thin by design: it holds no Docker
access and can only run a fixed allowlist of verbs, each as one SSH call through
a forced-command wrapper. The security model is documented separately in
[frontdoor-safety.md](frontdoor-safety.md).

## Enabling it

```
./mediastack.sh frontdoor-install
```

The first interactive run sets the panel's admin password (reused on re-runs;
`frontdoor-install --set-password` to change it). Then bring the stack up so the
panel container starts:

```
./mediastack.sh up
```

Reach it over HTTPS via Traefik at `https://${OLIVETIN_HOST:-panel}.<your
domain>` on the LAN, and log in as `admin`.

## What's on the panel

A single dashboard, grouped into sections:

- **Live status tiles** — one per enabled service, coloured by state (up /
  unhealthy / down), refreshed on a timer and by the Refresh button.
- **Diagnostics** (read-only) — Doctor, Status, VPN leak test, View logs.
- **Services** — Enable, Disable, Toggle VPN, Wire (pick a service from a
  dropdown; state-changers confirm first).
- **Maintenance** — Update stack, Backup now, Verify backup, Rollback, Unpin,
  Apply/reconcile, Fix perms, and Refresh panel.

Every button is exactly one whitelisted verb; the panel cannot run anything
else.

## Keeping it fresh

Dropdowns and status tiles are regenerated by `frontdoor-refresh` on a 5-minute
host timer, at install, and whenever you press **Refresh panel**.

## Appearance

The panel is themed with plain CSS at
`<CONFIG_ROOT>/olivetin/custom-webui/themes/mediastack/theme.css` (written by
`frontdoor-install`). Edit it and restart the panel container to iterate on the
look — but note `frontdoor-install` rewrites it, so durable changes belong in
the installer, not the live file.

## Configuration & safety

The panel's `config.yaml` is generated by `frontdoor-install`; edit
`mediastack.sh` (not the live config) for durable changes, then re-run the
installer. The allowlist, the wrapper, the narrow sudo entry, and the line on
which verbs are and aren't exposable are all covered in
[frontdoor-safety.md](frontdoor-safety.md).
