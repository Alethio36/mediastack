== GOTCHAS LEARNED (all cost a live round-trip; write them down) ==
  - compose.d/*.yml MUST be added to docker-compose.yml's `include:` — it's an explicit list, NOT a glob.
    (new-service dodges this by writing to docker-compose.override.yml instead.)
  - OliveTin `icon:` renders plain words as literal text; needs emoji / HTML entity / Iconify. Use emoji.
  - Container SSH client aborts "No user exists for uid 999" unless that uid is in the container's /etc/passwd
    -> we mount a generated passwd. And the account needs a real /bin/sh (nologin -> "account not available",
    sshd runs the shell before the forced command). The forced-command key is the lock, not nologin.
  - known_hosts: build from /etc/ssh/ssh_host_ed25519_key.pub. ssh-keyscan captured the SSH *banner*, not the key.
  - OliveTin default action timeout is ~3s — set per-action `timeout:` (update/doctor 300, status/leak 120,
    state-changers 180, vpn 300).
  - YAML: `on`/`off` are booleans — quote dropdown values ("on"/"off") or they become true/false.
  - `vpn <svc> on|off` only STAGES an overlay (prints "apply with: up"); it needs an explicit up. enable/disable/
    wire DO apply immediately.
  - OliveTin JSON entity files are JSONL (one object per line), not a JSON array.
